# Atmora Weather
Atmora Weather (or simply, Atmora) is an Android app for telling you the forecast for your home location, as well as your favorite locations.

## Features
- Viewing overview of the current forecast
- Viewing daily forecast
- Viewing hourly forecast
- Adding locations
- Assigning a home location
- Searching for cities using Open-Meteo Geocoding API
- Changing units in settings
